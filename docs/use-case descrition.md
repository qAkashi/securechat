Текстовое описание структуры Use-Case диаграммы
Акторы:

Пользователь (User): Инициализирует сессию, управляет ключами и ведет переписку.

Сервер чата (Chat Server): Управляет маршрутизацией зашифрованного трафика и комнатами.

Прецеденты использования (Use Cases) для Пользователя:

UC_1 Создать новую комнату (Генерирует уникальный токен комнаты).

UC_2 Присоединиться к существующей комнате (Требует ввода валидного токена).

UC_3 Управлять ключами безопасности (Просмотр, экспорт, генерация ключей).

UC_4 Отправить зашифрованное сообщение

<<include>> -> Шифрование текста на клиенте (AES-256).

UC_5 Получить и прочитать сообщение

<<include>> -> Дешифрование текста на клиенте.

UC_6 Покинуть чат / Уничтожить сессию (Очистка локального хранилища).

Прецеденты использования для Сервера чата:

UC_7 Проверить токен комнаты (Валидация при входе).

UC_8 Ретранслировать зашифрованный пакет (Пересылка сообщений подключенным клиентам без логирования).
